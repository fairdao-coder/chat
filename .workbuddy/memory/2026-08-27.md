## 登录页 UI 撕裂修复（用户截图反馈"好丑"）
- 根因：`App.tsx` 登录态 `return <Login ... />` 直接挂在 body 下，`<Login>` 根是 `<div className="login-screen">`，而 `.login-screen { flex:1 }` 需要父级 `display:flex` 才生效——无父级导致高度 = 卡片高 ≈380px，下方露出 body 灰底 `#c9ccd1`，上半部分仍被绿色渐变填满 → 视觉上是「绿条+白卡+灰底」三段撕裂。
- 修复：登录态改为 `<div className="auth-shell"><Login .../></div>`；新增 `.auth-shell { position:fixed; inset:0; background: 多层 radial+linear 渐变; }` 全屏品牌渐变（多个柔光圆环）+ 让 `.login-screen` 透明、`.login-card` 升级为 22px 大圆角玻璃感卡（多层阴影 + backdrop-filter blur(16px) + 内嵌 1px 白色描边）；品牌 logo 加 inset 高光；输入框加 `UserIcon`/`LockIcon` 前缀图标（`.field-icon` 绝对定位 42px 左留白）；主按钮改为 `btn-block` 渐变 + 阴影 + 按下回弹。`Icons.tsx` 新增 `LockIcon`。
- 验证：构建通过 → `dist-build2/`；预览面板已替换。

## 白天/黑夜主题切换（用户"支持白天黑夜切换"）
- 方案：把所有硬编码颜色收编为语义变量（`:root` 设计令牌），新增 `[data-theme='dark']` 覆盖块（深色背景 `#0b0b0c`/`#1c1c1e`、亮文本、暗气泡 `#2c2c2e`、品牌绿微调 `#2ecc71` 等）；登录页品牌渐变保持不变（始终品牌化）。
- 机制：`App.tsx` 加 `getInitialTheme()`（localStorage `theme` > 系统 `prefers-color-scheme: dark` 偏好 > light）、`theme` state、`toggleTheme()`，并在 `useEffect` 里 `document.documentElement.setAttribute('data-theme', theme)` + 持久化。切换按钮（SVG `SunIcon`/`MoonIcon`）加在 `ConversationList` 头部与 `ChatWindow` 头部（移动端聊天界面内也能切）。
- 验证：构建通过 → `dist-build3/`，CSS 13.31kB。MAUI 端未做暗色（源码级、本机不可编译），列为后续可选项。
- 复用坑延续：输出目录已用 `dist-build3`（每次重建换新目录名绕开 safe-delete 占用）。
